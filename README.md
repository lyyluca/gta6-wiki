# GTA6 Wiki

An independent, unofficial reference for Grand Theft Auto VI.

Website: [https://gtaviwiki.org/](https://gtaviwiki.org/)

## Overview
Character details, setting reveals, and platform updates are often discussed in different places. GTA6 Wiki groups those topics so readers can find a specific detail without starting with a chronological news feed.

## Features
- Character coverage for Jason and Lucia
- A guide to the six featured destinations in Leonida (Vice City, Leonard County, Vice Beaches, Kelly County, Port Gellhorn, and the Keys)
- GTA VI platform details and gameplay coverage
- Coverage of official Rockstar announcements

## How to use
1. Open [https://gtaviwiki.org/](https://gtaviwiki.org/) in your browser.
2. Select Characters, Leonida destinations, or game information relevant to your lookup.
3. Consult official Rockstar releases when exact wording or timing matters.
